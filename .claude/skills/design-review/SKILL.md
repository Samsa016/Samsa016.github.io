# Design Review: проверка на «дорого vs генерик»

Финальный фильтр. Прогоняй ПЕРЕД сдачей и после крупных правок. Честно — лучше найти
проблему самому, чем услышать «выглядит как шаблон» от клиента.

## Как проверять

Пройди по чеклисту. Каждый ❌-пункт, который сработал, — обязателен к исправлению.
В конце дай вердикт и список того, что чинить.

## A. Признаки ИИ-шаблона (если есть — ПРОВАЛ)

- [ ] Фиолетовые/сине-фиолетовые градиенты или дефолтный glassmorphism.
- [ ] Три (или N) одинаковые карточки с круглой иконкой по центру и текстом.
- [ ] Несколько центрированных симметричных секций подряд, одинаковый ритм.
- [ ] Скруглённые «пузыри» и мягкие тени на каждом блоке.
- [ ] Более одного акцентного цвета / акцентом залиты большие площади.
- [ ] Робкая мелкая типографика без контраста размеров.
- [ ] Тесная верстка без воздуха между секциями.
- [ ] Водянистый текст («качество, надёжность, индивидуальный подход»), остатки Lorem.
- [ ] Стоковые «бизнес-улыбки», кликпарт-иконки, разнокалиберные картинки.
- [ ] `#000`/`#fff` в чистом виде вместо тёплых почти-чёрного/белого.

## B. Признаки премиум (должны присутствовать)

- [ ] Щедрый воздух между секциями, верстка «дышит».
- [ ] Крупная выразительная типографика с большим контрастом размеров.
- [ ] Одна благородная нейтральная база + один скупой акцент.
- [ ] Есть асимметрия в раскладке хотя бы части секций.
- [ ] Метки секций капсом с широким трекингом.
- [ ] Качественные изображения в едином тоне/грейдинге.
- [ ] Плавные сдержанные scroll/hover анимации.
- [ ] Консистентные hover/focus состояния у всех интерактивных элементов.

## C. Техническое качество

- [ ] Адаптив без багов на 360 / 768 / 1280 / 1920, нет горизонтального скролла.
- [ ] Lighthouse: Performance ≥ 90, Accessibility ≥ 95, Best Practices/SEO ≥ 95.
- [ ] Один `h1` на страницу, корректная иерархия заголовков, alt у картинок.
- [ ] Контраст текста ≥ 4.5:1 (особенно приглушённый текст!).
- [ ] `prefers-reduced-motion` уважается, focus-стили видны.
- [ ] Токены вынесены, контент в `lib/content.ts`, нет магических чисел в JSX.

## D. «Прищуренный тест»

Прищурься и посмотри на страницу как на картинку (или уменьши до 25%):
- Есть чёткая визуальная иерархия и фокус? Или всё «серой кашей» одного веса?
- Выглядит как конкретный бренд или как «любой лендинг»?
- Захотел бы платить за такое 150к? Если нет — дорабатывай.

## Вердикт

```
Признаки шаблона (A): найдено N — перечислить
Премиум-маркеры (B): из 8 присутствует M
Техкачество (C): пройдено / проблемы: ...
Прищуренный тест (D): прошёл / нет
─────────────────────────────
ИТОГ: ДОРОГО / ЕЩЁ ГЕНЕРИК
Что чинить до сдачи: ...
```

Сайт можно объявлять готовым ТОЛЬКО при вердикте ДОРОГО и нуле пунктов из секции A.
