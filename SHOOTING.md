# Съёмка демок: что снято, что осталось

Правила съёмки — в скилле `video-demo`. Здесь только состояние по кейсам и
покадровые сценарии.

Бюджет каждого ролика: 8–12 с, немой, 1280×720, петля.
Три такта: **узнавание** (0–2 с) → **одно действие** (2–7 с) → **результат** (7–10 с).

## Могу снять сам, когда поднимется окружение (6)

Сценарии для них уже написаны или пишутся в `scripts/record-demos.mjs` —
нужен только работающий адрес.

### `agora` — приоритет первый

**Блокер: `agora.24rbs.ru` не отвечает.** DNS резолвится в `5.42.124.191`,
соединение отваливается по таймауту. Пока сервер лежит, утверждение «задеплоен
и открыт» в кейсе неверно — либо поднять, либо убрать из `proof`.

Сценарий, как только адрес живой:
1. Каталог с товарами, крупно (2 с).
2. Открыть карточку товара, положить в корзину (3 с).
3. Чекаут: тестовая карта `4242 4242 4242 4242`, оплата проходит (4 с).
4. Замереть на подтверждённом заказе — это постер.

### `voicedesk`

Запуск: `cd voice_agent && docker compose up --build`, демо на
`http://localhost:8000/demo/`. Ключи не нужны — `MOCK_MODE=1` по умолчанию.
Снимать **дашборд** (`localhost:3000`, пароль `admin`), а не микрофон: живые
транскрипты по WebSocket читаются без звука, а разговор — нет.

1. Дашборд с воронкой и списком звонков (2 с).
2. Начинается звонок — транскрипт печатается в реальном времени (5 с).
3. В карточке появляется забронированная встреча (3 с).

### `autoscraper`

Нужны БД и `.env`. Снимать связку админки и бота:
1. Админка со списком собранных объявлений (2 с).
2. Запрос боту «найди красную BMW до 2 млн» (3 с).
3. Ответ — отфильтрованная выдача (4 с). Это и есть function calling в деле.

### `smartembed`

1. Виджет на чужом сайте, свёрнутый (2 с).
2. Вопрос по содержимому этого сайта (3 с).
3. Ответ с цитатой из проиндексированной страницы (4 с).

### `mindtrack`

1. Список записей дневника (2 с).
2. Открыть запись — видны тональность и извлечённые темы (3 с).
3. График корреляции настроения со сном (4 с).

### `browser-agent` и `midnight`

Терминальные. Снимать реальный прогон окна: шрифт 16–18 pt, тёмная тема,
окно без заголовка и панелей.

- `browser-agent`: команда задачи → на скриншоте проступает нумерованная
  разметка Set-of-Marks → агент кликает по номеру и доходит до результата.
- `midnight`: лог конвейера — источник опрошен, заказ прошёл четыре ступени
  оценки, письмо сгенерировано и поставлено в очередь.

## Снимаешь ты (1)

### `lapka` — Telegram, нужен твой аккаунт

Снимать вертикально, запись экрана телефона. Шторку уведомлений убрать,
яркость на максимум, режим «не беспокоить». Один дубль, без монтажа.

| Секунда | Что делаешь |
|---|---|
| 0–2 | Открыт чат с ботом, видна прошлая переписка. Не двигаешься |
| 2–4 | Зажимаешь микрофон, наговариваешь короткую заметку про щенка |
| 4–5 | Отпускаешь, сообщение уходит |
| 5–7 | Приходит расшифровка — держишь кадр |
| 7–10 | Приходит тёплый ответ и список побед с категориями. Замираешь на нём |

Пришли исходник как есть, любым весом — обрежу и сожму сам:
`scripts/encode.sh <файл> lapka <старт> <длительность>`.

Чего в кадре быть не должно: чужих чатов в списке, реальных имён и телефонов,
уведомлений сверху.

## Клиентские кейсы

Съёмки не будет ни у одного. Показывать интерфейсы с данными заказчиков нельзя,
а синтетические скриншоты «как бы из продакшена» — это подделка. Эти пять кейсов
подаются текстом: задача, решение, проверяемые факты.
