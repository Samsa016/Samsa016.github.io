# CLAUDE.md — сайт-портфолио

## Что это

Портфолио фриланс-разработчика. Витрина ~28 работ, разложенных по четырём главам-годам:
frontend → fullstack → AI-интеграции → AI-агенты. Ядро — видеодемки кейсов, которые
играют при наведении, и переход в разбор по клику.

**Полное ТЗ — `TZ.md`. Читать целиком до любого кода.**

**Визуальная система — `DESIGN.md`.** Принята 31.08.2026 после разбора референсов
владельца; уточняет `TZ.md` §4 и раздел «Фон и цвет» ниже. Где расходится с ними —
прав `DESIGN.md`, он новее. Каталог референсов с пометками «что берём» —
`REFERENCES.md`, незакрытые пункты — `DESIGN-BACKLOG.md`.

## Главная планка

Сайт продаёт разработчика будущим клиентам. Если он выглядит как ИИ-шаблон или
конструктор — задача провалена, сколько бы он ни «работал». Здесь дизайн и текст
важнее количества фич.

## Рабочий цикл (строго по порядку)

0. Прочитать `TZ.md`, затем `DESIGN.md` — он новее и переопределяет §4.
1. До первой строчки разметки — активировать `/frontend-design:frontend-design`
   и локальный скилл `premium-design`.
2. **Сначала дизайн-система, потом страницы.** Токены (палитра, типографика, сетка,
   отступы, motion) — в `app/globals.css` через `@theme`. Только потом компоненты.
3. Компоненты пишем сами. Контент — в `lib/content/`, в JSX ничего не хардкодим.
4. Текст кейсов — только через скилл `case-copy`.
5. Видеодемки — только через скилл `video-demo`.
6. Графики, схемы, диаграммы — через `/dataviz`.
7. Перед словом «готово» — прогон `design-review`. Вердикт «ДОРОГО» и ноль пунктов
   секции A, иначе дорабатываем.
8. Перед публикацией — чеклист приватности (ниже).

## Стек (фиксированный)

Next.js 16 App Router · TypeScript · Tailwind v4 · `motion` · `next/font/google`
(шрифты скачиваются на сборке и раздаются со своего домена).
Без UI-китов, без готовых темплейтов, без Bootstrap.

**Сборка — статический экспорт** (`output: "export"`), деплой — GitHub Pages.
Vercel не подходит: он отдаёт 403 на весь трафик из сети владельца, включая API.
Отсюда два следствия, которые нельзя нарушать: серверных возможностей Next
(middleware, route handlers, оптимизатор картинок, ISR) в проекте нет, а сайт
обязан оставаться переносимым — `out/` должен работать на любом статик-хостинге.

## Жёсткие правила

**ЗАПРЕЩЕНО (признаки ИИ-шаблона):**
- фиолетово-синие градиенты, дефолтный glassmorphism;
- три одинаковые карточки с иконками-кружочками по центру;
- симметричные центрированные секции одна за другой;
- закруглённые «пузыри» и мягкие тени;
- более одного источника цвета (единственный акцент приходит из `--case-tint`);
- заливка любой плоскости цветом работы: тинт допустим только как свет — ореол,
  свечение, градиент от края (`DESIGN.md` §1);
- тёплые оранжевые градиентные фоны, блоки доверия с метриками клиентов
  («500K+ / 98%»), неоновые 3D-сцены — забракованные референсы владельца;
- `#000` и `#fff` в чистом виде;
- водянистый текст, Lorem ipsum, эмодзи в контенте;
- стоковые фотографии — **запрет снят владельцем 27.08.2026**: сток допустим,
  но текущее направление обходится без него, поэтому вводить фото — только
  по отдельному решению, а не «чтобы оживить».

**Фон и цвет (27.08.2026, частично переопределено `DESIGN.md` от 31.08.2026 —
цвет работы теперь светится, а не заливает; см. `DESIGN.md` §1):**
- под страницей два закреплённых слоя: свет (два источника, сверху-слева и
  снизу-справа) и материал (крапчатость на пределе различимости). Заливку держит
  только `html` — продублируешь её на `body`, и она закроет собой оба слоя;
- `--case-tint` есть у **каждой** из 27 работ, а не только у тех, что сняты:
  где есть кадр — доминанта постера, где нет — цвет интерфейса самой работы;
- блок работы несёт свой цвет фоном (`.case-field`), поэтому цвет живёт всегда,
  а не только под курсором. Глава размечена тоном (`.chapter-field`), без краски.

**ОБЯЗАТЕЛЬНО:**
- воздух между секциями, крупная типографика, асимметрия;
- `prefers-reduced-motion` уважается везде, где есть движение;
- видимые focus-стили, контраст ≥ 4.5:1;
- все числа в кейсах — настоящие, из README/кода/тестов.

## Приватность (нарушать нельзя)

Клиентские кейсы публикуются **только обезличенно**: отрасль + масштаб + задача +
интеграции + срок. Никаких названий компаний, ФИО, телефонов, email, номеров заказов
и договоров, никаких скриншотов с реальными данными.

Проверка перед каждым деплоем — `pnpm privacy`. Ищет телефоны, почтовые адреса,
номера заказов и договоров, а также имена заказчиков из рабочих папок.

Единственное законное исключение — собственные контакты владельца: они вынесены
в `lib/owner.ts`, и только этот файл исключён из поиска. Не добавляй новых
исключений: если проверка ругается, правильный ответ — убрать данные из контента,
а не расширить список.

## Definition of Done

- [ ] `pnpm build` без ошибок и предупреждений типов.
- [ ] До наведения на кейс браузер не тянет ни одного видеофайла (проверять в Network).
- [ ] Быстрый проход курсором по всей сетке не оставляет играющих видео.
- [ ] Клавиатура: Tab по кейсам, видео стартует по фокусу, Enter ведёт в кейс.
- [ ] При `prefers-reduced-motion` — ни автозапуска, ни Set-of-Marks, ни скролл-анимаций.
- [ ] Адаптив 360 / 768 / 1280 / 1920, горизонтального скролла нет.
- [ ] Lighthouse: Performance ≥ 90, Accessibility ≥ 95, Best Practices/SEO ≥ 95.
- [ ] `pnpm privacy` — чисто.
- [ ] `design-review` даёт «ДОРОГО».
